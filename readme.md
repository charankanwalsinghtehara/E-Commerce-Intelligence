# Customer Churn Intelligence Platform

## 📌 Project Overview

Customer Churn Intelligence Platform is an end-to-end Data Analytics and Machine Learning project designed to analyze e-commerce customer behavior and predict the probability of customer churn.

The project combines Data Analysis, SQL, Exploratory Data Analysis, Customer Segmentation, Feature Engineering, Machine Learning, and an interactive Streamlit dashboard.

The primary focus of the project is Data Science and Data Analytics. The user interface is used only to present the analytical insights and machine learning predictions in an interactive format.

---

# 🎯 Business Problem

Customer churn is a major challenge for e-commerce businesses.

When customers stop purchasing, businesses lose potential future revenue.

The objective of this project is to:

- Analyze customer purchasing behavior.
- Identify patterns associated with customer churn.
- Segment customers using RFM analysis.
- Build machine learning models to predict churn.
- Identify high-risk customers.
- Convert model predictions into business-friendly risk categories.
